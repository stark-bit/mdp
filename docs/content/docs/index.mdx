[markdown-preview](https://github.com/sammaji/markdown-preview.nvim) previews
markdown files in your browser. The page updates as you edit the file, and
renders math, diagrams and GitHub-flavoured markdown, in the look of any
shadcn/ui theme.

It runs from one command, `markdown-preview file.md`, on macOS, Linux, FreeBSD
and Windows. Everything is bundled into a single binary, so it runs offline
(no CDN) and needs no Node.js at runtime.

Fork of [iamcco/markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim),
rewritten as a standalone preview server.
