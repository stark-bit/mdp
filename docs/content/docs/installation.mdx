`markdown-preview` is a single self-contained binary. Pre-built binaries are
published for:

| System  | Architectures |
| ------- | ------------- |
| macOS   | x64, arm64    |
| Linux   | x64, arm64    |
| FreeBSD | x64           |
| Windows | x64           |

On anything else, [build the server from source](#building-from-source).

## Download a release binary

Grab the archive for your system from the
[releases page](https://github.com/sammaji/markdown-preview.nvim/releases),
for example `markdown-preview-linux-arm64.tar.gz`, and put the binary on your
`PATH`.

macOS and Linux:

```sh
tar -xzf markdown-preview-macos-arm64.tar.gz
sudo mv markdown-preview-macos-arm64 /usr/local/bin/markdown-preview
```

Windows: extract `markdown-preview-win.zip` and add the folder containing
`markdown-preview.exe` to your `PATH`.

FreeBSD:

```sh
tar -xzf markdown-preview-freebsd.tar.gz
mv markdown-preview-freebsd /usr/local/bin/markdown-preview
```

## Building from source

```sh
git clone https://github.com/sammaji/markdown-preview.nvim.git
cd markdown-preview.nvim
cargo build --release
```

The binary is at `target/release/mm`.

This needs [Rust](https://rustup.rs) 1.86+ and Node.js 20.9+ with pnpm or npx.
Node.js is only needed to build the preview page (`cargo build` builds it into
the binary); running the preview needs nothing else. To reuse an already-built
page, set `MKDP_SKIP_PAGE_BUILD=1`.

## Checking the installation

```sh
markdown-preview --version
```

prints the version. Then preview any markdown file:

```sh
markdown-preview README.md
```
