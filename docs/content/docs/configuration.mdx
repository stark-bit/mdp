## Setting options

The server reads options from a TOML file and from command-line flags:

1. The built-in defaults.
2. The config file: `markdown-preview.toml` in the current directory, or the
   file given with `--config`.
3. The command-line flags, which override the config file.

```toml
theme = "dark"
port = 8090
```

```sh
markdown-preview --port 8090 --no-open note.md
```

A config file must be valid TOML; unknown keys warn on stderr and are
ignored. A missing `markdown-preview.toml` is fine; a missing `--config` file
warns and the defaults are used.

<Callout type="info">
The config file is read once at startup. Restart the server to apply changes.
</Callout>

## Command-line flags

```text
markdown-preview [flags] [files...]
```

| Flag                 | Description                                                                     |
| -------------------- | ------------------------------------------------------------------------------- |
| `[files...]`         | Markdown files to preview; each gets its own page and URL                        |
| `--config <path>`    | Config file to read; default `markdown-preview.toml` in the current directory    |
| `--port <n>`         | Port to serve on; the next free port is used when the first 20 are taken         |
| `--root <dir>`       | Directory the previewed files must live under; default the current directory     |
| `--browser <cmd...>` | Browser to open the URL in; a name, a comma-separated list or a JSON array       |
| `--no-open`          | Print the URL but do not open a browser                                          |
| `--version`          | Print the version                                                                |

`--browser` takes every following argument until the next flag, so put file
names before it:

```sh
markdown-preview note.md --browser firefox --new-window
```

Each file is previewed at `/files/<its path relative to the root>`, and its
URL is printed on stdout. The browser is opened for each file unless
`--no-open` is given.

## Options

The default is shown after each name.

### Server and network

#### `port`: unset

Port of the preview server. Without it, the server starts at a random port
around 8080 and falls back to the following ports. With `port` set (or
`--port`), the next 20 ports are tried and the server exits with an error if
none is free.

#### `open_to_the_world`: `false`

Listen on all network interfaces instead of only `127.0.0.1`, so other
devices on your network can open the preview. The preview URL then uses your
machine's IP address and carries a secret token, and the server answers
nothing without it. See [Sharing on your
network](./features/browser.mdx#sharing-on-your-network).

#### `open_ip`: unset

Host or IP address used in the preview URL instead of `localhost`, for
example when you run the server on a remote machine and preview on your own.

### Browser

#### `browser`: unset

The browser to open the preview in; unset uses the system's default browser.

- A name, such as `"firefox"` or `"Google Chrome"`, is opened the way the
  system opens applications: `open -a` on macOS, `start` on Windows, and run
  as a program on Linux.
- An array is run as a command with the URL appended:
  `["firefox", "-P", "work"]`.

See [Browser and sharing](./features/browser.mdx) for new windows, WSL and
other examples.

### Page

#### `theme`: unset

`"dark"` or `"light"`. Unset follows the system preference. The button in the
page header switches it until the page is closed.

#### `theme_css`: unset

Path of a [shadcn/ui or tweakcn theme](./features/themes.mdx), which
changes the page's colors, fonts and radius.

#### `markdown_css`: unset

Path of a stylesheet that replaces the built-in markdown styles.

#### `highlight_css`: unset

Path of a stylesheet that replaces the built-in code highlighting colors.

#### `page_title`: unset

Title of the browser tab. `${name}` is replaced with the file name:

```toml
page_title = "Preview: ${name}"
```

#### `images_path`: unset

Directory that relative image paths are resolved against. Unset uses the
directory of the markdown file.

## Preview options

`preview_options` is a table in the config file that controls how the page
renders. Keys you leave out keep their defaults.

```toml
[preview_options]
front_matter = "panel"
```

#### `mkit`

[markdown-it options](https://github.com/markdown-it/markdown-it#init-with-presets-and-options).
The defaults turn on raw HTML, `linkify` and `typographer`. Use
`{ html = false }` to not render raw HTML from files you don't trust.

#### `katex`

[KaTeX options](https://katex.org/docs/options), e.g. `{ macros = { "\\RR" =
"\\mathbb{R}" } }`. Errors are shown in red instead of stopping the page.

#### `uml`

PlantUML: `server` (default `https://www.plantuml.com/plantuml`),
`imageFormat` (default `img`, or `svg`), and `openMarker` / `closeMarker`
(default `@startuml` / `@enduml`) for bare PlantUML blocks.

#### `maid`

[Mermaid options](https://mermaid.js.org/config/schema-docs/config.html), e.g.
`{ layout = "elk" }` for the ELK layout of dense graphs. Mermaid's `theme`
follows the page's light or dark theme unless you set it here.

#### `sequence_diagrams`

[js-sequence-diagrams](https://bramp.github.io/js-sequence-diagrams) options.
The default theme is `"hand"`; `{ theme = "simple" }` draws straight lines.

#### `flowchart_diagrams`

[flowchart.js options](https://flowchart.js.org).

#### `toc`

[markdown-it-toc-done-right options](https://github.com/nagaozen/markdown-it-toc-done-right#options).
The list is a `ul` by default.

#### `front_matter`

YAML front matter at the top of the file:

- `"hide"` (default): not shown
- `"panel"`: a collapsed panel that shows the YAML
- `"raw"`: rendered as markdown

#### `hide_yaml_meta`

The older form of `front_matter`: `0` is `"raw"`. `front_matter` wins when
both are set.

#### `content_editable`

`true` makes the page editable, e.g. to try out wording. Edits stay in the
page and are lost on the next refresh; they are not written to the file.

#### `disable_filename`

`true` hides the header with the file name.

## Environment variables

Set these when you start the server, for debugging:

| Variable       | What it does                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `MP_LOG_FILE`  | Server log file. Default: `markdown-preview-<uid>.log` (`markdown-preview.log` on Windows) in the temp directory, alternating with `markdown-preview-<uid>.1.log` once one passes 1 MB. |
| `MP_LOG_LEVEL` | `debug` (without `MP_LOG_FILE`, each session logs to its own `markdown-preview-<uid>.debug-<time>-<pid>.log`), `info` (default) or `error`. |
