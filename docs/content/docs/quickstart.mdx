## Requirements

- A web browser
- A pre-built server binary, or [Rust](https://rustup.rs) to build one

Node.js is not needed to run the preview.

## Install

Download the release for your system from the
[releases page](https://github.com/sammaji/markdown-preview.nvim/releases) and
put the binary on your `PATH`:

```sh
tar -xzf markdown-preview-macos-arm64.tar.gz
sudo mv markdown-preview-macos-arm64 /usr/local/bin/markdown-preview
```

macOS, Linux (x64 and arm64), FreeBSD (x64) and Windows (x64) have pre-built
binaries. On other systems, or to run your own build:

```sh
cargo build --release
```

in a checkout of this repository. See
[Installation](./installation.mdx) for the details of each.

## Open a preview

```sh
markdown-preview README.md
```

The server prints the preview URL and opens it in your browser:

```text
http://localhost:8123/files/README.md
```

Edit `README.md` in any editor and save — the page updates by itself, without
a reload. Press `Ctrl-C` to stop the server.

Use `--no-open` to only print the URL, and `--port 8090` to pin the port.

To see every feature at once, preview
[`examples/features.md`](https://github.com/sammaji/markdown-preview.nvim/blob/master/examples/features.md).

## Change a few settings

Options live in `markdown-preview.toml` in the directory you run the server
from:

```toml
# always use the dark theme instead of following the system
theme = "dark"
# open the preview in this browser instead of the default one
browser = "firefox"

[preview_options]
front_matter = "panel"
```

Every option is in the [configuration reference](./configuration.mdx).

## When something is wrong

Run the server with debug logging and look at the log file:

```sh
MP_LOG_LEVEL=debug markdown-preview README.md
```
